# ВИСНОВКИ

У ході лабораторної роботи було реалізовано послідовний та паралельний алгоритм Гаусса для розв’язання систем лінійних рівнянь. Порівняння із послідовним алгоритмом показало, що при малих розмірах матриць (до 100×100) паралельна обробка не дає виграшу через накладні витрати на передачу даних між процесами. Починаючи з розмірів 500×500, алгоритм демонструє поступове прискорення, досягаючи 1.5–2 разів при використанні 4 процесів та близько 2.7 разів при 8 процесах.

Основними труднощами при реалізації стали синхронізація процесів на кожному етапі алгоритму та нерівномірність розподілу обчислень між ними. Під час пошуку опорного елемента та виконання виключення стовпців частина процесів простоює, що зменшує ефективність паралельного розрахунку. Також спостерігається накопичення похибок у результатах через багаторазові обміни числовими значеннями між процесами.

Загалом паралельна реалізація алгоритму Гаусса забезпечує помітне скорочення часу виконання для великих систем рівнянь. Однак ефективність зростає не лінійно зі збільшенням кількості процесів, адже зростають витрати на комунікацію. Таким чином, реалізований паралельний алгоритм підтвердив доцільність використання паралельних обчислень для великих задач, але також показав, що подальше прискорення можливе лише за умови оптимізації комунікаційних операцій і балансування навантаження між процесами.
