# ВИСНОВКИ

У ході виконання лабораторної роботи було реалізовано та досліджено послідовний і паралельний алгоритми множення матриць, зокрема алгоритм Фокса, з використанням бібліотеки MPI. Метою роботи було порівняти ефективність обчислень на різній кількості процесів та проаналізувати вплив розміру матриці на швидкодію програми.

Під час експериментів встановлено, що для малих матриць паралельна реалізація виконується повільніше за послідовну. Це пояснюється значними накладними витратами на ініціалізацію процесів, передачу даних між ними та синхронізацію. Для невеликих задач такі витрати перевищують час самого обчислення.

Однак зі зростанням розміру матриць ефективність паралельного алгоритму різко підвищується. Починаючи з матриць розміру приблизно 
500×500 спостерігається стабільне прискорення, а при великих розмірах (3000×3000) досягається майже ідеальне масштабування - на 9 процесорах час виконання скоротився у 9,4 раза порівняно з послідовним алгоритмом. Це підтверджує правильність реалізації методу Фокса та його здатність ефективно розподіляти обчислювальне навантаження між процесами.

Таким чином, паралельний алгоритм є значно ефективнішим для великих обсягів даних, де переважають обчислювальні операції над комунікаційними. Для невеликих задач доцільніше використовувати послідовну реалізацію. Отримані результати експериментально демонструють фундаментальний принцип паралельних обчислень - оптимальне співвідношення між розміром задачі та кількістю процесів визначає реальну продуктивність системи.
