# Висновки

Під час виконання лабораторної роботи було реалізовано послідовну та паралельну версії алгоритму Зейделя для розв’язання системи диференціальних рівнянь на основі сіткової апроксимації. Метою роботи було дослідити вплив кількості процесів на час виконання обчислень та оцінити ефективність паралельної реалізації за допомогою технології MPI.

Результати експериментів показали, що зі збільшенням розміру сітки паралельна реалізація демонструє суттєве скорочення часу виконання порівняно з послідовною. Для малих розмірів (до 500 елементів) спостерігалося незначне або відсутнє прискорення, що пояснюється накладними витратами на комунікацію між процесами. Для більших сіток (2000–10000 елементів) спостерігається стабільне зростання швидкодії: при 2 процесах швидкість зростає до 1.75 разів, при 4 — до 3.2, а при 8 процесах — до 2.6 разів відносно послідовного варіанту.

Такі результати свідчать, що паралельна реалізація методу Зейделя є ефективною для великих систем диференціальних рівнянь, де обсяг локальних обчислень суттєво перевищує витрати на обмін даними. Для невеликих задач, навпаки, накладні витрати на синхронізацію між процесами нівелюють переваги паралельності. Отже, метод Зейделя у паралельній формі доцільно застосовувати для задач великої розмірності, де він забезпечує помітне прискорення та ефективне використання ресурсів багатопроцесорних систем.
