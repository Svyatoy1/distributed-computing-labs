# Висновки

Під час виконання лабораторної роботи було реалізовано послідовний і паралельний алгоритми Флойда — методу пошуку найкоротших шляхів між усіма вершинами графа. Для дослідження ефективності використовувались різні кількості процесів (2, 4, 8), що дало змогу оцінити вплив паралельної обробки на швидкодію програми.

Результати показали, що навіть при відносно малих розмірах графів (500–1000 вершин) паралельна реалізація демонструє суттєве скорочення часу виконання. Прискорення (speed-up) зростає від 3–5 разів при 2 процесах до понад 8–9 разів при 8 процесах для великих графів. Це пояснюється ефективним розподілом підматриць між процесами та паралельним оновленням рядків матриці відстаней.

Для невеликих графів (до 100 вершин) прискорення практично не спостерігається — накладні витрати на комунікацію між процесами та синхронізацію даних у MPI перевищують виграш від паралельних обчислень. Водночас для великих обсягів даних паралельна версія стає ефективнішою, оскільки частка часу, витрачена на обмін повідомленнями, стає незначною порівняно з обсягом локальних обчислень.
